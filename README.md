# To-Do Management API

A robust, production-ready RESTful API for managing tasks, projects, workspaces, subtasks, tags, time tracking, and user authentication. Built with Laravel 13, PostgreSQL, Redis, and Docker.

## Features

- **Authentication & Authorization** – Laravel Sanctum with token-based auth, role-agnostic access control via workspace membership.
- **Workspace Management** – Create workspaces, add/remove members, each workspace has its own projects and tags.
- **Project Management** – Projects belong to a workspace, with visibility levels: `private`, `team`, `public`.
- **Task Management** – Full CRUD, status (`todo`, `in_progress`, `in_review`, `done`), priority (`urgent`, `high`, `normal`, `low`), due dates, assignees (single + multiple), tags, subtasks, and custom ordering.
- **Subtask Management** – Nested tasks with completion toggle.
- **Tag Management** – Color-coded tags per workspace, attach many-to-many to tasks.
- **Time Tracking** – Log time entries (minutes) per task, automatic aggregation of `time_spent`, update `time_estimate`.
- **Dashboard & Statistics** – Task counts by status/priority, upcoming/overdue/recent tasks, workspace summary, overall user summary.
- **Soft Deletes & Restore** – All core entities support soft deletion with restore endpoints.
- **Audit Log** – Task logs automatically record `created`, `updated`, `status_changed`, `priority_changed`, `deleted`, `restored` actions.
- **Search & Filter** – Advanced query filtering with pagination, sorting, and eager loading via `Winata\QueryBuilder`.
- **API Documentation** – Interactive Swagger UI generated by Scramble (available at `/docs/api`).

## Project Structure

The code follows a **clean architecture** pattern:

- **Models** – Eloquent models with UUIDs, soft deletes, and relationships.
- **Enums** – Backed enums for `TasksStatus`, `TasksPriority`, `ProjectVisibility`, `TasksLogActions`, and `Table` (centralised table names).
- **Queries** – `BaseQueryBuilder` implementations for filtering, sorting, and includes (`TaskQuery`, `WorkspaceQuery`, `ProjectQuery`, `TagQuery`, `SubTaskQuery`).
- **Services** – Business logic and validation (`TaskService`, `WorkspaceService`, `ProjectService`, `TagService`, `SubTaskService`, `DashboardService`).
- **Controllers** – Route attributes via `Dentro\Yalr`, dependency injection, response wrapping.
- **Resources** – API transformation (e.g., `TaskResource`, `WorkspaceResource`).
- **Policies** – Authorization (e.g., `TaskPolicy` checks workspace membership).

## Setup Instructions

### Prerequisites

- Docker & Docker Compose (recommended) or PHP 8.3, Composer, PostgreSQL 15, Redis 7, Node.js & npm.

### Option 1: Using Docker (production-like)

```bash
git clone <repository-url>
cd todo-app

# Copy environment file
cp .env.example .env

# Build and start containers
docker-compose up -d --build

# Run migrations (if not run automatically)
docker exec -it laravel_app php artisan migrate

# Generate API documentation (optional)
docker exec -it laravel_app php artisan scramble:export

# The API will be available at http://localhost:8000
```

### Option 2: Local development (without Docker)

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate

# Configure .env with your PostgreSQL and Redis credentials
php artisan migrate
php artisan db:seed  # optional

php artisan serve
npm run dev  # for frontend assets (optional)
```

## API Endpoints Overview

All authenticated endpoints require a Bearer token obtained from POST `/api/auth/login` or `/api/auth/register`.

### Public endpoints

- POST /api/auth/register
- POST /api/auth/login

### Protected endpoints (under `/api`, versioned)

| Resource      | Methods                         | Description                                    |
|---------------|---------------------------------|------------------------------------------------|
| Workspaces    | GET, POST, PUT, DELETE, PATCH   | Manage workspaces and members                  |
| Projects      | GET, POST, PUT, DELETE, PATCH   | Manage projects within workspaces              |
| Tasks         | GET, POST, PUT, DELETE, PATCH   | Full task CRUD + custom actions                |
| Subtasks      | GET, POST, PUT, DELETE, PATCH   | Subtask management and toggle completion       |
| Tags          | GET, POST, PUT, DELETE, PATCH   | Manage tags per workspace                      |
| Time Tracking | POST, GET, PUT                  | Log time, view logs, get totals, set estimate  |
| Dashboard     | GET                             | Statistics, upcoming/overdue/recent tasks      |

Detailed interactive documentation is available at `/docs/api` when the application is running.

## Example requests

Register a user:

```bash
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"John Doe","email":"john@example.com","password":"secret123","password_confirmation":"secret123"}'
```

Login:

```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"john@example.com","password":"secret123"}'
```

Create a workspace (authenticated):

```bash
curl -X POST http://localhost:8000/api/workspaces/create \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"name":"My Workspace","description":"Team workspace"}'
```

Create a project:

```bash
curl -X POST http://localhost:8000/api/projects/create \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"name":"Backend API","workspace_id":"...","visibility":"team"}'
```

Create a task with tags and multiple assignees:

```bash
curl -X POST http://localhost:8000/api/tasks/create \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"title":"Implement rate limiting","description":"Use Laravel throttle middleware","priority":"high","due_date":"2025-06-01","project_id":"...","tags":["tag-uuid-1","tag-uuid-2"],"assignees":["user-uuid-1","user-uuid-2"]}'
```

Log time on a task:

```bash
curl -X POST http://localhost:8000/api/tasks/{taskId}/time/log \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"minutes":45,"description":"Code review and refactoring"}'
```

Get dashboard summary:

```bash
curl -X GET "http://localhost:8000/api/dashboard/overall-summary" \
  -H "Authorization: Bearer {token}"
```
